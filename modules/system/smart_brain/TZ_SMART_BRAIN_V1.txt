SMART BRAIN v1
Technical Specification
Target: Stable Smart Brain architecture capable of reaching 70–80% winrate in simulator.

IMPORTANT RULES
---------------

1. Do NOT redesign architecture.
2. Do NOT add new AI/ML features.
3. Do NOT modify existing modules outside smart_brain.
4. Work only inside:

modules/system/smart_brain/

5. Do NOT break existing UI layout.
6. Every stage must compile and run without errors.

====================================================
PHASE 1 — UI STABILIZATION
====================================================

Goal:
Stable visual interface for Smart Brain.

Tabs must exist:

1 Dashboard
2 Global Config
3 Analyzer
4 Simulator
5 Coin Passports
6 Runtime

Dashboard must display:

cards:
- Candidates
- Monitors
- Signals
- Simulator Positions

tables:
- Monitors
- Simulator Waiting
- Simulator Active
- Simulator Closed


Status values:

monitoring
entry_zone
triggered
invalidated


DO NOT modify design further after stabilization.



====================================================
PHASE 2 — GLOBAL CONFIG CENTER
====================================================

Goal:
Centralized configuration system.

Config files:

config/parser4.php
config/corridor.php
config/risk_engine.php
config/simulator.php
config/profiles.php
config/ui.php

Aggregator:

config/config.php


Each config must support:

mode:
manual
auto

Example structure:

return [

    "mode" => "manual",

    "settings" => [

        "enabled" => true

    ],

    "auto_rules" => [

        "allow_brain_override" => false,

        "override_fields" => []

    ]

];


Runtime overrides:

runtime/config_overrides/*.json

Effective config =

base config + override



====================================================
PHASE 3 — PARSER4 ANALYZER
====================================================

Goal:
Generate market candidates.

Parser4 must NOT generate trading signals.

Input sources:

parser.parser3_manager_behavior.storage
parser.parser2_history_accumulator.storage


Output:

storage/candidates.json


Candidate structure:

{

symbol

corridor_low

corridor_high

corridor_width

volatility

strength

trend_bias

}


Analyzer tab must display these fields.



====================================================
PHASE 4 — CORRIDOR MONITOR
====================================================

Goal:
Transform candidates into monitored trade opportunities.

File:

lib/corridor_monitor.php


Input:

candidates.json

Output:

monitors.json


Monitor structure:

{

symbol

corridor_low

corridor_high

entry_zone_low

entry_zone_high

status

}


Status states:

monitoring
entry_zone
triggered
invalidated



Entry zone defined by:

corridor width * entry_zone_percent



====================================================
PHASE 5 — COIN PASSPORTS
====================================================

Goal:
Maintain long-term statistics per symbol.

Location:

storage/passports/SYMBOL.json


Passport structure:

{

symbol

corridor_width_avg

volatility_avg

speed_class

pattern_history

avg_mae

avg_mfe

avg_duration

winrate

reliability_score

}


Passports updated automatically after each simulator cycle.



====================================================
PHASE 6 — RISK ENGINE
====================================================

Goal:
Convert monitors into trade signals with calculated risk.

File:

lib/risk_engine.php


Inputs:

monitor
passport
profile limits


Outputs:

signal parameters:

symbol
entry_zone
leverage
budget
stop_loss
take_profit



Profiles are LIMITERS only.

Profile example:

budget
max_leverage
stop_loss_range
slippage
trailing
take_profit



====================================================
PHASE 7 — SIGNAL BUILDER
====================================================

Goal:
Generate final signal objects.

Output:

storage/signals.json

Signal structure:

{

symbol

entry_zone_low

entry_zone_high

corridor_low

corridor_high

leverage

budget

status

}



====================================================
PHASE 8 — SIMULATOR ENGINE
====================================================

Goal:
Test signals without live trading.

Simulator must ALWAYS run.

Tables:

Waiting
Active
Closed


Waiting structure:

symbol
entry_zone
budget
leverage
stoploss
takeprofit


Active structure:

symbol
entry_price
current_price
ROI
leverage
stoploss
takeprofit


Closed structure:

symbol
entry
exit
ROI
reason
duration



====================================================
PHASE 9 — METRICS
====================================================

Simulator must calculate:

total_trades
winrate
average_roi
median_mae
median_mfe
median_duration
signal_to_entry_conversion


Minimum evaluation size:

150 trades.



====================================================
PHASE 10 — TUNING FOR TARGET WINRATE
====================================================

Allowed tuning parameters:

parser4 thresholds
corridor entry zone
risk scaling
passport filters


DO NOT add new features before metrics stabilize.

TARGET RESULT

Smart Brain must reach:

70–80% winrate

in simulator environment
